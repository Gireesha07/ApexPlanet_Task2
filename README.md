# ApexPlanet Task 2 - Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a sales dataset using Python, SQL Server, and Excel.

## Tools Used
- Python
- Pandas
- Matplotlib
- SQL Server (SSMS)
- Microsoft Excel

## Project Structure
- dataset/ - Original and cleaned datasets
- scripts/ - Python EDA script
- images/ - Charts and visualizations
- dashboard/ - Excel dashboard
- sql/ - SQL queries used for analysis

## Key Features
- Data cleaning and preprocessing
- SQL data analysis
- Data visualization
- Interactive Excel dashboard
